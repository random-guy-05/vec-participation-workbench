# Official sources

Checked 14 October 2026. These pages are authoritative and may change after this snapshot.

| Tool | Source and relevant fact |
|---|---|
| Board Coverage Planner | [Official Rules §13](https://virtualembryo.ai/challenge/rules): each task is averaged across its boards, then the three task scores are summed; an unattempted board counts as zero. |
| Generality Architecture Mapper | [Official Rules §14](https://virtualembryo.ai/challenge/rules): enter at least two tasks with one shared model architecture; task-specific inputs/heads and per-task training are allowed. |
| Team Contribution Ledger | [Official Rules §§2, 7](https://virtualembryo.ai/challenge/rules): listed members must have made a genuine contribution; a team has up to ten members. |
| Compute Budget Estimator | [Challenge data](https://virtualembryo.ai/challenge/data): T1 has 32,285 genes; T2/T3 use a 500-gene panel; T2/T3 submissions also carry three spatial coordinates. |
| Deadline Calendar Exporter | [Official timeline](https://virtualembryo.ai/challenge/timeline): milestone dates included in the exported calendar. |
| Experiment Plan Card | [Official Rules §§9–11](https://virtualembryo.ai/challenge/rules): Agent Team lock/evidence boundary, use of released data, and submission limits; [official evaluation](https://virtualembryo.ai/challenge/evaluation): scoring definitions. |
| Team Eligibility Checklist | [Official Rules §§2, 6–9](https://virtualembryo.ai/challenge/rules): captain, account, team size, track, eligibility and Agent Team conditions. |
| Data-use Readiness Checklist | [Official data page](https://virtualembryo.ai/challenge/data) and [Publish with us](https://virtualembryo.ai/challenge/publish): acknowledge the data-generating groups, and obtain prior written approval before public presentation or publication using the unpublished Challenge data. |
| Good First Contribution Finder | [Community resources](https://virtualembryo.ai/challenge/resources): check existing work before creating a duplicate. Suggestions are examples, not organizer-assigned tasks. |
| Help Request Builder | [Official FAQ](https://virtualembryo.ai/challenge/faq) and [community resources](https://virtualembryo.ai/challenge/resources): use public channels and public artifacts for support. Do not include private or unpublished data. |
| Contribution Brief Builder | [Community resources](https://virtualembryo.ai/challenge/resources): check existing work; contribution criteria value original, useful, finished work. |
| Community Resource Review | [Community resources](https://virtualembryo.ai/challenge/resources): review public materials and avoid duplicating them. Tool outputs are reviewer notes, not organizer findings. |
| Accessibility Review Checklist | [W3C WAI accessibility guidance](https://www.w3.org/WAI/standards-guidelines/wcag/) provides general accessibility reference; the checklist is a practical review aid, not a conformance audit. |
| Peer Session Agenda Builder | [Community resources](https://virtualembryo.ai/challenge/resources): published resources can be selected as session material. The time allocation is editable and is not an official curriculum. |
| Discussion-to-Action Notes | No rule-specific facts. The template encourages public references and privacy-conscious meeting notes. |
| Project Handoff Card | No rule-specific facts. The template is for public artifacts and excludes credentials, private data, and unpublished results. |
| Synthetic Data Lab | No Challenge data or task-schema facts. It creates deterministic generic toy counts and explicitly does not produce valid Challenge inputs or submissions. |
| Quickstart Guide Builder | [Official data page](https://virtualembryo.ai/challenge/data) and [community resources](https://virtualembryo.ai/challenge/resources) are examples of authoritative sources a guide author can link; outputs are templates. |
| Micro-Lesson Blueprint | [Official rules](https://virtualembryo.ai/challenge/rules) and [community resources](https://virtualembryo.ai/challenge/resources) are suggested primary references for challenge-specific lessons. |
| Scientific Figure Description Builder | [W3C image accessibility tutorial](https://www.w3.org/WAI/tutorials/images/) gives general advice on text alternatives; the generated text still needs human review. |
| Source Freshness Tracker | [Official rules](https://virtualembryo.ai/challenge/rules) and [official timeline](https://virtualembryo.ai/challenge/timeline) are examples of time-sensitive pages to recheck. The reminder does not fetch or validate links. |
| Feedback Triage Planner | No official prioritization score. The formula is an explicit local discussion heuristic only. |
| Community Project Starter | [Citation File Format schema guide](https://github.com/citation-file-format/citation-file-format/blob/main/schema-guide.md): CFF requires author metadata; generated collective-author placeholder should be replaced or edited for actual creators. |
| Community Release Notes Builder | No rule-specific facts. The form prompts maintainers to link current official sources for challenge-specific statements. |
| HPC Job Log Doctor | No rule-specific facts. The parser matches common error text; cluster administrators' documentation is authoritative for site-specific diagnosis and commands. |
| Runtime Forecast Planner | No rule-specific facts. It extrapolates only from participant-provided pilot timings and does not estimate queue wait, peak memory, or guaranteed runtime. |
| Verified Download Script Builder | The [official data page](https://virtualembryo.ai/challenge/data) is where users should obtain current public data links. The builder does not provide URLs or checksums; users must verify the source and checksum independently. |
| Pseudobulk Aggregator | No challenge-specific facts. The user selects grouping columns and aggregation; the page warns to preserve biological samples as replicates. |
| Design Confounding Auditor | No challenge-specific facts. The categorical design rank is an algebraic diagnostic, not a claim about biological identifiability beyond the supplied factors. |
| Rare-State Sampling Planner | No challenge-specific facts. Uses a binomial sampling model with fixed prevalence; it is not a power analysis. |
| Cell Composition Distance Explorer | No challenge-specific facts. Bray–Curtis and Jensen–Shannon distances are computed from user-entered per-sample counts. |
| Composition–Expression Decomposer | No challenge-specific facts. Uses a symmetric two-condition decomposition of user-supplied means and composition proportions. |
| Gene Signature Coverage Auditor | No challenge-specific facts. Exact identifiers are compared; aliases and orthologs are not inferred. |
| Gene Set Enrichment Calculator | No challenge-specific facts. Hypergeometric over-representation depends on a user-supplied eligible universe and user-supplied sets. |
| Replicate-Aware Contrast Reporter | No challenge-specific facts. Descriptive sample-level effects only; it does not compute p-values. |
| Single-Cell QC Threshold Explorer | No challenge-specific facts. Thresholds are user-specified and are not recommended by the tool. |
| Per-Cell Signature Scorer | No challenge-specific facts. Uses within-matrix gene-wise z-scores from user-provided normalized values. |
| Stage Trend & Forecast Explorer | No challenge-specific facts. Linear/quadratic fits and leave-one-stage-out diagnostics are descriptive, not independent validation. |
| Cell-Label Transition Explorer | No challenge-specific facts. The output describes supplied source/target labels; it does not establish lineage. |
| Cell-Label Mapping Auditor | [Official data page](https://virtualembryo.ai/challenge/data) notes that annotation vocabulary differs across stages and a harmonized mapping is being developed. The tool only aggregates according to user-entered mappings; no label equivalence is official or inferred. |
| VEC Data Release Map | [Official data page](https://virtualembryo.ai/challenge/data) and [Tasks](https://virtualembryo.ai/challenge/tasks) describe the stage/condition splits, modalities, and held-out targets shown. Current sources control if the map becomes stale. |
| Compute Access Route Planner | [Official data page](https://virtualembryo.ai/challenge/data) gives task input dimensions and data access rules; [Rules](https://virtualembryo.ai/challenge/rules) define held-out data restrictions. The route is participant-selected and makes no hardware or runtime guarantee. |
| Gene Detection Rate Analyzer | No challenge-specific facts. Detection fractions and positive-value means depend on user-selected data scale and zero threshold. |
| Replicate Concordance Reporter | No challenge-specific facts. Pearson/Spearman correlations are descriptive and do not justify dropping samples. |
| 3D Coordinate Alignment Explorer | No challenge-specific facts. PCA centering/rotation is a coordinate transform and does not register anatomy to a reference atlas. |
| Spatial Neighborhood Radius Explorer | No challenge-specific facts. Euclidean distances use the input coordinate units and scale. |
| Spatial Occupancy Grid Comparator | No challenge-specific facts. Voxel Jaccard/Dice are exploratory and not official VEC scores. |
| 3D Spatial Autocorrelation Explorer | No challenge-specific facts. Moran’s I is descriptive; the tool does not calculate a permutation p-value. |
| Metric Contract Diff | [Official reference rows and panel contracts](https://virtualembryo.ai/challenge/baselines); [veckit issue #1](https://github.com/aristoteleo/veckit/issues/1) and [issue #3](https://github.com/aristoteleo/veckit/issues/3) document open questions about canonical versions and metric/panel scope. The diff does not resolve them. |
| Metadata Schema & Drift Comparator | No challenge-specific facts. The comparator checks user-supplied metadata snapshots and does not match rows by identifier. |
| Challenge Service Incident Packet | [veckit issue #10](https://github.com/aristoteleo/veckit/issues/10) records a reported sign-in/service outage. The packet builder does not check live availability; use the official [Challenge account](https://virtualembryo.ai/challenge/account) and support channels for current status. |
| VEC Task Metric Lab | [Official scoring reference](https://virtualembryo.ai/challenge/evaluation?section=scoring) defines the metric directions, skill transform, group weights, and task aggregation. The calculators are small-data explanations and are not the official scorer. |
| Metric Invariance Audit Sheet | [Official scoring definitions](https://virtualembryo.ai/challenge/evaluation?section=scoring) describe metric behavior; the audit expects users to derive assertions from the current specification and does not certify a scorer implementation. |
| Prediction Schema Fixture Generator | [Official data page](https://virtualembryo.ai/challenge/data) documents each task's prediction panel sizes and spatial schema. The script requires the user's local official panel file, creates fake expression only, and is not a prediction or valid submission. |
| Source Overlap Audit | No Challenge-specific facts. It performs exact identifier matching on a user-pasted manifest, with optional case folding explicitly controlled by the user; it does not infer aliases, establish biological identity, or decide data eligibility. |
| Hierarchical Replicate Bootstrap | No Challenge-specific facts. The equal-sample bootstrap assumes the supplied sample IDs are independent experimental units; the intervals are exploratory and do not correct confounding, dependence, or model misspecification. |
| Cell-Label Ontology Crosswalk Curator | No external ontology lookup. CURIE validation checks only identifier shape; ontology existence, namespace release, and biological equivalence must be confirmed by participants. |
| Grouped Validation Walkthrough | [Official data page](https://virtualembryo.ai/challenge/data) and [rules](https://virtualembryo.ai/challenge/rules) provide current task split definitions; the code itself uses synthetic data and illustrates general validation logic, not a prescribed split for every task. |
| Independent Replicate Precision Planner | No Challenge-specific facts. It uses a normal-approximation interval for a single mean and user-supplied pilot variance; it is not a power analysis or study-size guarantee. |
| Minimal Reproducer Builder | No external facts. It samples and transforms user-supplied CSV data locally; pseudonymization is reversible only with the source data and does not guarantee anonymity or safe disclosure. |
| Compositional Closure Demonstrator | No Challenge-specific facts. It simulates independent Poisson counts and shows the mathematical effect of dividing each count by a shared total; the output is not biological evidence. |
| Holdout Split Auditor | [Official data page](https://virtualembryo.ai/challenge/data) describes the current task splits; this tool checks only the user-provided manifest and does not validate an official Challenge submission or define an approved split. |
| Training Seed Stability Report | [Official scoring reference](https://virtualembryo.ai/challenge/evaluation?section=scoring) describes score direction by metric; participants must select the appropriate direction and ensure runs use comparable splits and metric versions. |
| Matched Reference Coverage Auditor | [Official data page](https://virtualembryo.ai/challenge/data) and [task definitions](https://virtualembryo.ai/challenge/tasks) describe current data conditions; the tool only counts user-selected values and does not certify matching or eligibility. |
| Count Dispersion Explorer | No Challenge-specific facts. It samples the stated Poisson and negative-binomial distributions from user-selected synthetic parameters; it does not fit or compare models on Challenge data. |
| Library-Size Normalization Demonstrator | No Challenge-specific facts. It uses fixed synthetic library sizes and binomial feature counts to illustrate one-feature scaling; it is not a recommended normalization method or model. |
| Dataset Provenance Manifest Builder | No external metadata verification. It serializes participant-entered citation and provenance fields; license, checksum, eligibility, and citation accuracy remain unverified. |
| Gene Panel Intersection Planner | [Official data page](https://virtualembryo.ai/challenge/data) links to the current gene panels; the page compares only the exact identifiers users paste and does not resolve synonyms or orthology. |
| Gene Rank Stability Reporter | No Challenge-specific facts. It computes descriptive pairwise statistics on participant-supplied gene effects and exact identifiers; its outputs are not official VEC scores or inferential tests. |
| External Data Eligibility Checker | [Official data page](https://virtualembryo.ai/challenge/data) sets the T1 E9.5–E13.5 exclusion window, Task 2 interpolation boundaries and proximity rule, and Task 3 held-out genotypes; [Rules](https://virtualembryo.ai/challenge/rules) require disclosure of external sources. The checker is a screening aid, not an organizer decision. |
