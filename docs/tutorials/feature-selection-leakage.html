Fit Feature Selection Inside the Training Split

A short scikit-learn walkthrough showing how supervised feature selection performed before the split can make a noise-only model appear predictive.

Download the Python walkthrough View source

The failure pattern

A supervised selector such as ANOVA F-score uses labels to decide which genes or features to retain. If it sees test labels before the model split, it can select features that fit random fluctuations in both training and test data. The later test score is no longer an independent evaluation.

The safer pattern is to split first and put every learned preprocessing or feature-selection step inside a pipeline that is fitted on training data only. Keep the official Challenge split and rules as the authority for actual evaluations.

What the script does

  1. Generate 400 examples with 300 independent noise features and random binary labels.
  2. Measure a leaky score after selecting features from all labels before splitting.
  3. Measure again using a scikit-learn pipeline fitted only on training rows.
  4. Compare both with chance performance; results vary across seeds.

There is no predictive signal in this synthetic dataset. The example is deliberately constructed to expose evaluation leakage.

Run locally

python -m pip install numpy scikit-learn
python feature-selection-leakage.py

Use your own held-out groups and task-specific validation design for real work. The example does not prescribe a split, feature count, or model for VEC.
