Keep Samples Together When You Validate

A short, runnable demonstration of how a random cell split can overstate generalization when the real question is performance on new biological samples.

Download the Python walkthrough View source

The evaluation question comes first

If the intended use is predicting cells from a new embryo, donor, or biological replicate, the validation split should hold out that independent unit. Randomly assigning individual cells can place highly similar cells from one sample in both training and test sets. A model can then recognize sample-specific structure that will not be available for a new sample.

The Challenge tasks have different train/test designs, so participants should follow the current task definitions and rules. This tutorial shows the general reasoning; it does not claim that one cross-validation scheme is correct for every VEC task.

What the script demonstrates

  1. Create a synthetic dataset where many cells share one sample-level label and nearby feature profiles.
  2. Measure accuracy after a row-wise split that lets samples appear on both sides.
  3. Measure accuracy with GroupKFold, keeping every sample in one fold.
  4. Compare the results and decide which split answers the intended generalization question.

The sample signature and labels are deliberately constructed for teaching. They are not Challenge data, biological observations, or a model result.

Run it locally

python -m pip install numpy scikit-learn
python grouped-validation.py

The script prints the row-wise accuracy, each held-out-sample fold score, and the grouped mean. Your exact outputs may vary if you change the seed or synthetic data settings.

When to adapt this pattern

  • Choose a grouping column that matches the independent unit relevant to deployment or scientific inference.
  • Keep all cells from a group on one side of each split when evaluating transfer to unseen groups.
  • For paired designs, time-series forecasting, or the Challenge's official splits, use a split strategy that matches that design rather than copying this toy setup.
  • Report the number of independent groups and fold-level results; many cells do not replace biological replication.
