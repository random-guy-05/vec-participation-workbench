Batch Adjustment Trade-off Playground

Add observations to the off-diagonal condition-by-batch combinations and see how overlap affects identifiability and estimates.

Adjust the controls to explore this deterministic synthetic example.

Assumptions and limits

The synthetic data have a fixed treatment effect, a batch shift, and sample-level noise. At zero off-diagonal overlap, condition and batch are perfectly confounded, so the separate treatment effect is not identifiable. Added overlap permits an additive two-factor estimate but does not guarantee balance, adequate power, correct model assumptions, or control of unmeasured confounders.

All values are synthetic and generated in this page. The demonstration does not load Challenge data or make a biological finding.
