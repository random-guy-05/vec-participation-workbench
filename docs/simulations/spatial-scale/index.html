Spatial Neighborhood Scale Playground

Change a distance radius and see how the edges and label mixing in a toy spatial graph change together.

State the graph definition

This deterministic two-dimensional point set is synthetic. An undirected edge is drawn when Euclidean distance is at most the selected radius. The displayed cross-label fraction is descriptive and depends on point density, labels, coordinate units, and radius.

For real tissue, document coordinate units, dimensionality, segmentation quality, and the neighborhood rule. A change in radius changes the scientific question; do not choose a scale only because it produces a preferred pattern.
