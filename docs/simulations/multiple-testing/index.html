Multiple Testing Expectation Explorer

See how a per-test threshold behaves when many true-null hypotheses are examined.

Two different summaries

Among m₀ true-null tests, the expected number below an unadjusted threshold is m₀ × α. If null p-values are independent and calibrated, the chance of at least one false positive is 1 − (1 − α)m₀. The chart compares the expected false-positive fraction with the family-wise probability, both on a 0–100% scale.

Real tests can be dependent, and estimated null proportions or miscalibrated p-values change these quantities. This illustration does not calculate adjusted p-values or recommend a threshold.
