Range Restriction Correlation Explorer

Narrow the sampled predictor range while leaving the underlying synthetic relationship and noise unchanged.

Adjust the controls to explore this deterministic synthetic example.

Assumptions and limits

The full synthetic sample has x uniformly distributed from −1 to 1 and the same linear outcome-generating equation at every x value. The restricted sample includes only |x| below the selected limit. Correlation can change because the sampled range changes; this does not imply the underlying slope changed, and the restricted sample is smaller.

All values are synthetic and generated in this page. The demonstration does not load Challenge data or make a biological finding.
