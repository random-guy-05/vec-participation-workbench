Optional Stopping Demonstrator

Increase the number of interim looks at the same synthetic null data and observe the empirical false-positive rate.

Adjust the controls to explore this deterministic synthetic example.

Assumptions and limits

The page simulates independent standard-normal observations under a true zero effect. At each scheduled look it checks the same accumulating sample against |z| > 1.96; the comparison uses one pre-specified final look. Repeated checks are dependent because they reuse data. This illustration is not a substitute for a preplanned sequential design or an exact test for a particular study.

All values are synthetic and generated in this page. The demonstration does not load Challenge data or make a biological finding.
