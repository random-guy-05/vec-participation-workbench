Missing-Data Bias Playground

Change the mechanism and missing fraction to see how incomplete observations affect a simple two-group contrast.

Adjust the controls to explore this deterministic synthetic example.

Assumptions and limits

Two synthetic groups have a known mean difference of 0.60. The MCAR mode removes observations independently; the group-dependent mode changes missingness rates by observed group; the outcome-dependent mode makes higher outcomes more likely to be missing. Complete-case analysis is not generally unbiased under outcome-dependent missingness. Coding missing values as zero is shown only as a deliberately naive comparison, not as a recommended imputation method.

All values are synthetic and generated in this page. The demonstration does not load Challenge data or make a biological finding.
