Log-Transform Compression Explorer

Move the baseline and fold change to see how a log transform compresses high counts.

Adjust the controls to explore this deterministic synthetic example.

Assumptions and limits

The left and right charts use separate vertical scales. The page shows the same multiplicative change on its original count scale and after log₂(1 + count). The transform compresses high values and changes the meaning of differences; it does not by itself normalize library size, remove mean–variance structure, or make data normally distributed.

All values are synthetic and generated in this page. The demonstration does not load Challenge data or make a biological finding.
