What normalization does and does not do

When the underlying feature fraction is the same, a group with more reads per cell tends to have more raw counts. Dividing by each cell's total library size puts counts on a common per-10,000 scale; log1p then compresses that scale.

Here, each simulated cell has a fixed total count within its group, and the feature count is drawn from a binomial model. The controls change the feature's true fraction independently of the library-size ratio, so you can see whether normalization preserves a relative change in this simplified setting.

This is a single-feature toy example, not a normalization recommendation, differential-expression model, or VEC prediction. It does not handle composition bias, cell-level covariates, zero inflation, or the official task's supplied expression scale. All data stay in this browser.
