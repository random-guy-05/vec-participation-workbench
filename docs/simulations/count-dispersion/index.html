Modeling notes

For the Poisson distribution, variance equals the mean. This negative-binomial parameterization has variance mean + mean² / size; smaller size produces greater overdispersion. Both simulated distributions use the same mean.

This illustrates a distributional choice, not a fitting procedure or evidence that one model suits a dataset. Use raw integer counts for count-model assumptions; transformations, normalization, and sampling design change the interpretation.
