Compositional Closure Demonstrator

Simulate independent noisy counts for three cell populations, then compare one pair as raw counts and as fractions of a total. The fractions must sum to one, which can create relationships that are absent from the absolute counts.

Run the simulation to compare correlations from independent counts with correlations after converting counts to proportions.

Why this happens

For each sample, all proportions share the same denominator: the total number of cells. With only two parts, their fractions sum exactly to one and therefore have a perfect negative relationship. With more parts, closure still constrains the fractions and can induce correlations even when the underlying count processes were generated independently.

Cell counts and proportions answer different questions. Counts depend on sampling depth and total abundance; proportions describe relative composition. Neither view alone establishes a biological interaction or causal change.

The simulated counts are independent Poisson draws for teaching. This is not a VEC dataset, official scoring formula, or substitute for a compositional-data model. No data are uploaded.
