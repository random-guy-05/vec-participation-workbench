Metric Behavior Playground

Apply an offset, scale change, or one outlier to a toy prediction and compare three familiar metrics.

Interpretation matters

On the fixed reference sequence 1–8, Pearson correlation measures linear association, Spearman correlation measures rank association, and RMSE measures absolute error in the same units as the values. A constant offset can leave both correlations at 1 while worsening RMSE; a positive scale change does the same. A single extreme point can affect correlation and RMSE differently.

These are not interchangeable measures, and this toy example does not specify the official Challenge score. Always check the task's scoring definition and whether it rewards calibration, ranking, or shape.
