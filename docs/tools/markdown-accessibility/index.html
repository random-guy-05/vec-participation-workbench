Markdown Accessibility Quick Scan

Catch common structural barriers in a draft Markdown guide: skipped heading levels, vague link text, missing image descriptions, and unclosed code fences.

The scan runs in this tab. It does not send or store the pasted document, and exported findings omit the source text.

Paste Markdown to review

Paste text only—no file upload. The quick scan checks heading outline, link labels, image alt text, and fenced code blocks; it does not fetch links.

Scan the example or paste a draft to review.

What this scan cannot decide

  • A meaningful alternative text depends on the image's purpose; this scan can find an empty alt field but cannot write or judge a description.
  • Heading and link-text heuristics are prompts for review. A heading sequence can be technically ordered and still be confusing.
  • Reference-style links, embedded HTML, tables, color contrast, keyboard behavior, and screen-reader output need separate review.
  • No automatic correction is applied. Review the document in context and ask people who use assistive technology to test it.

This is a small Markdown pattern scan, not a conformance or accessibility certification.
