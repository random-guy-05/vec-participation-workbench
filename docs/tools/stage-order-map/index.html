Turn stage labels and participant-supplied numeric time/order values into an explicit, sorted mapping for a downstream analysis or chronological split audit.

This page uses only values you enter. It does not infer chronology or upload or save your table.

Build the example or paste a stage map.

Interpretation limits

  • The map preserves the numeric values you provide; it does not convert labels into ages, infer missing stages, or assume equal spacing.
  • Equal numeric values are kept as ties. Check whether tied labels are intended to represent the same time point.
  • A correct chronological mapping does not by itself make a train/validation/test split valid. Check sample and correlated-group overlap separately.
  • Review stage definitions against the dataset source and current official task documentation before using this map.

This is a transparent mapping helper, not a developmental biology authority or split validator.
