Environment Snapshot Builder

Generate a small Python script for a focused support request: Python version, operating-system family, architecture, and selected package versions. Optionally check PyTorch CUDA availability.

This page creates code only. It does not inspect your computer, run the script, or upload information.

Generate the script, review it, and decide whether its output is appropriate to share.


  

  

    
Before sharing a report

    
    
      
  • The script prints only Python version, OS family, machine architecture, requested distribution versions, and—if selected—PyTorch CUDA availability/version/device count.
    • 
      
  • It does not print usernames, hostnames, file paths, environment variables, tokens, package inventories beyond your list, or data values.
    • 
      
  • The optional GPU probe imports PyTorch and can take time or initialize CUDA. Leave it unchecked if that is unsuitable on a shared cluster.
    • 
      
  • Review both the script and its output before posting. Environment metadata can still identify a specialized setup; this is a troubleshooting aid, not a privacy audit.
    • 
    

    
The script uses Python's standard library for platform and package metadata. It never contacts a network service; the optional probe requires PyTorch already to be installed.
