How the calculation works

For each task, the tool averages the board scores across every row listed for that task. A blank score contributes zero. It then sums the three task averages. If a task has no rows, its contribution is zero. This follows Rules §13; the board roster can change, so review it before using the result.

The tool does not predict scores, infer hidden targets, or turn returned scores into prediction values.
