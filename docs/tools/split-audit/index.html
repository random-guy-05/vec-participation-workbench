Holdout Split Auditor

Inspect a user-defined split manifest for sample groups or exact cell identifiers assigned to more than one partition. This is a leakage screen for your local validation design, not a validator for the official Challenge submission.

Paste the split manifest

Use one row per cell or sample. Repeated sample_id values within a split are expected for cell-level data.

Read the findings

  • A sample_id assigned to multiple split labels may mean related observations cross the boundary. Confirm that sample_id represents the independent unit for your question.
  • An exact cell_id found in multiple splits is a direct duplicate-identifier signal; it still needs checking against the source manifest.
  • Different split labels or imbalanced condition counts are reported as supplied; this tool does not prescribe a split or decide whether the design is valid.

Current Challenge train, validation, and hidden-test rules are defined by the official data page and rules. This browser-local tool uses only the CSV you paste and does not upload or store it.
