Training Seed Stability Report

Summarize repeated-run scores and compare two methods across common seeds. See whether an apparent improvement is consistent across training randomness instead of relying on one favorable run.

Paste repeated-run scores

Use one row per method and seed. The page does not calculate a p-value or estimate biological-sample uncertainty.

Interpretation limits

  • Paired differences are calculated only for seed values present in both methods. Seed matching is meaningful only if the same seed plays a comparable role in both runs.
  • Run-to-run variation reflects the training procedure and supplied score; it does not replace uncertainty across biological samples or held-out examples.
  • Compare the same task, data split, metric version, and evaluation inputs. This tool does not verify those conditions or determine official metric direction.

All data stay in this browser tab. The output is a descriptive reproducibility summary, not a statistical significance test, official scorer, or leaderboard claim.
