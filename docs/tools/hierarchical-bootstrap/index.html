Hierarchical Replicate Bootstrap

Estimate a two-group mean difference by resampling independent samples first, then observations within each selected sample. Compare it with the naive pooled-observation difference to see how unequal cell counts change the estimand.

Configure the comparison

Use one row per cell or observation. Multiple observations may share the same independent sample_id.

What the estimate means

  • The reported difference is mean(Group B sample means) − mean(Group A sample means), so each independent sample gets equal weight.
  • Each bootstrap draw resamples independent samples within group, then resamples observations within each selected sample. The percentile interval describes sampling variability under that design.
  • The pooled-cell difference gives every observation equal weight and can answer a different question when sample sizes differ.

Use biological replicate identifiers for sample_id. This version assumes independent groups and asks you to use a paired method if the same biological unit appears in both groups. The bootstrap cannot fix confounding, non-independent replicates, an incorrect experimental unit, or a poorly chosen model. It is an exploratory statistic, not an official VEC metric or leaderboard score. All data stay in this tab and are not uploaded.
