Read metrics with the class balance

  • Precision and negative predictive value depend on class prevalence; they may change when prevalence changes even if sensitivity and specificity do not.
  • Balanced accuracy is the mean of sensitivity and specificity. MCC summarizes all four cells and is undefined when its denominator is zero.
  • Counts must come from the same held-out evaluation set and a clearly specified threshold. Do not tune a threshold on the set used for the final report.
  • These summaries do not account for clustered observations, uncertainty, calibration, or task-specific scoring rules.
