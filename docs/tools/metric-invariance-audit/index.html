Metric Invariance Audit Sheet

Compare baseline and transformed synthetic-control scores against an expectation you specify, with explicit absolute and relative tolerances.

The tool does not decide which invariances an official metric should have. Record the scorer version, controlled transformation, and rationale from the current specification before interpreting a result.

Enter paired control results

Use one row for each metric and transformation. “same” checks the tolerance; “different” checks that the observed difference exceeds it; “unspecified” records the difference without a pass/fail judgment.

Enter paired results and the behavior you expect from each controlled transformation.

Make the comparison reproducible

  • Use synthetic or otherwise permitted data, and keep the original and transformed inputs identical except for the named change.
  • Record the scorer package version or full commit, random seed, transformation details, and any preprocessing shared by both runs.
  • Interpret a failed check as a prompt to reproduce and inspect the implementation. It is not proof of a bug or of an official scoring defect.
