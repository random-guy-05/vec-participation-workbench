Enter group counts

Enter successes and totals for both groups.

Assumptions and limits

  • The interval uses Newcombe's method based on separate Wilson score intervals; it is not a pooled Wald interval.
  • Groups must be independent, with binomial outcomes and well-defined denominators.
  • It does not adjust for clustering, repeated measurements, covariates, or multiple comparisons.
  • The interval describes a proportion difference; it does not explain why groups differ or establish biological importance.
