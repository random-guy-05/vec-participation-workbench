What the result means

This is a pattern matcher, not a scheduler diagnosis. It reports matched line numbers and common next checks; it does not execute commands or change your job. Scheduler configuration, cluster policies, and module names vary.

For a useful public help request, include the scheduler, requested resources, exit state, and the first relevant error. Do not post credentials, private paths, or Challenge-held-out data.

Recognized clues include memory and time limits, preemption, missing software, filesystem and quota errors, network failures, malformed HDF5 files, and CUDA memory errors. A line can match more than one clue.

All analysis runs locally in this browser. Check existing community resources before creating a duplicate.
