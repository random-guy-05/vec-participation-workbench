Community Project Starter

Prepare the three files a newcomer and maintainer need first: a useful README, small contribution guide, and machine-readable citation metadata.

Download README.md with the main button. The other buttons create a basic CONTRIBUTING.md and CITATION.cff from these inputs. Review every file and choose a license appropriate to your project before publishing.

Nothing is published by this tool. Files are generated in your browser for you to review.

Before making the repository public

Review the content, remove credentials and private data, verify that linked examples can be shared, and confirm you have the right to apply the selected license. Replace the placeholder author in CITATION.cff; edit the collective name into structured personal-author fields when appropriate. This generator does not create a GitHub repository or make files public.
