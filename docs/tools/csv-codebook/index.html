How to use the result

  • Detected types are simple heuristics over non-empty values. They do not validate scientific meaning, units, or an official submission schema.
  • Distinct counts and missingness describe the pasted rows only; they may differ from the full dataset.
  • No example values are exported, which reduces accidental disclosure but also means this codebook cannot demonstrate value conventions.
  • Review column descriptions and remove identifiers or confidential notes before sharing an exported dictionary.

This is a lightweight documentation aid, not a data-quality certification or Challenge validator. Check current official data and task guidance before relying on a schema.
