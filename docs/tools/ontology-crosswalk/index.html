Status must be proposed, reviewed, or unmapped. A CURIE is checked for prefix:identifier shape only. This page does not fetch an ontology or verify that an identifier exists.

Paste the labels and proposed mapping, then review coverage, syntax, evidence, and duplicate targets.

Review before sharing

  • Unmapped labels remain visible; the tool never guesses a cell type from a name.
  • Many source labels can map to one CURIE, but each merge should have an explicit biological rationale.
  • “Reviewed” is a status entered by your team. It does not mean the tool or an ontology authority validated the mapping.

All parsing and reporting happen in this browser tab. Pasted labels and notes are not uploaded or saved. The exported CSV is a review artifact, not a replacement for the source annotations.
