Verified Download Script Builder

Create a small Bash script for resumable public HTTPS downloads. Add a published SHA-256 digest when one is available so the script can check the completed file.

Format: https://public.example/file.h5ad[TAB]optional SHA-256[TAB]optional filename. URLs with credentials, query strings, or fragments are rejected to avoid embedding secrets.

Add at least one public HTTPS URL.

Review before you run it

  • The generated script downloads files only; it does not run or install them.
  • It resumes incomplete .part files and moves a completed download into place. Existing destination files are left untouched and cause the script to stop.
  • If you provide a digest, the script checks the file before finalizing it. Without a digest, successful HTTP transfer is not proof of file integrity.
  • Use only URLs and data you are permitted to download. Never put login credentials, access tokens, or private signed URLs into this tool.

The script uses curl and Bash, available on many Linux/macOS systems. Check your cluster's transfer and storage policies.

The URL list and generated script remain in this browser. Nothing is uploaded or executed.
