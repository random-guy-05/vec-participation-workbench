Planning limits

  • The matrix is a Cartesian product, so it includes every entered combination. Remove invalid or scientifically unjustified combinations before running it.
  • The wall-time estimate assumes each run takes the measured duration and workers stay busy. It excludes setup, queue delay, stragglers, failures, and shared-resource contention.
  • A run list does not make comparisons fair: use the same data boundaries, scoring procedure, and selection rule across candidates.
  • A task or board label here is only a user label. Confirm current official split and submission rules separately.

Use a short pilot from the same workflow to estimate per-run time. Treat the result as a planning scenario, not a guaranteed runtime or validation design.
