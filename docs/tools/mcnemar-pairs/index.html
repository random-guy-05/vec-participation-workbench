Matched Binary Outcome Comparator

Compare two binary outcomes measured on the same units with an exact McNemar test and paired rate difference.

Only 0/1 pairs are processed in this tab. Outputs are aggregate counts; no rows are uploaded.

Enter one matched A,B pair per line

Use 1 for yes/success and 0 for no/failure; use comma or tab separation. A recognized first header A,B is optional.

Enter at least two matched pairs.

What the exact test uses

  • The exact two-sided p-value conditions on the number of discordant pairs and uses a binomial null probability of one half in either direction.
  • The paired rate difference is (A yes − B yes) divided by all matched units; it reports magnitude and direction separately from the p-value.
  • Use genuinely matched units and one independent pair per unit. This test does not handle clustering, weights, or missing-pair mechanisms.
  • If comparing classifiers, define the binary outcome consistently (for example, correct/incorrect) before entering results.
