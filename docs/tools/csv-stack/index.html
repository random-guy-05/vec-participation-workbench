DATA INTEGRATION · BROWSER-LOCAL

CSV Row Stack & Provenance Builder

Append two tables that have the same columns, even when their column order differs. Optionally add a source label to each output row.

Everything runs in this tab. Rows are not uploaded or saved; the combined file is created only when you download it.

Paste the tables to stack

Each CSV may have up to 20,000 rows and 2 MB. Both tables need the same distinct column names; columns align by exact header name, not position.

Stack the example or paste your own two tables.

Scope and review

  • This app appends rows; it does not join records by key or remove duplicates.
  • Headers must match exactly after surrounding spaces are trimmed. It does not infer aliases, rename fields, or fill missing columns.
  • Choose source labels that do not reveal private paths or people. If opened in a spreadsheet, review values that begin with formula characters.
  • The preview shows at most 20 output rows. Review the full downloaded CSV and retain a backup of the inputs.
