ROC AUC Bootstrap Interval Planner

Estimate tie-aware ROC AUC and a seeded stratified percentile-bootstrap interval from binary labels and continuous scores.

Labels and scores stay in this tab. The result contains aggregate metrics, not input rows.

Enter one actual,score pair per example

Scores may be any finite number; label 1 is positive and label 0 is negative. Header actual,score is optional.

Use at least two positive and two negative examples.

The interval is conditional on observed class counts

  • AUC estimates P(score positive > score negative) plus half the tie probability; it measures ranking, not probability calibration or a chosen threshold.
  • The stratified bootstrap resamples positives and negatives separately, keeping the observed class counts fixed.
  • Percentile-bootstrap intervals can be unstable with small samples or ties. The seed makes this implementation repeatable; it does not improve the data.
  • Use independent held-out examples. This tool does not adjust for repeated subjects, clusters, or model selection on the evaluation set.
