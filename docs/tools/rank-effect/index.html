Probability of Superiority and Rank-Biserial Effect Size

Summarize how often a randomly chosen value from one independent group exceeds a value from another, counting ties as half.

Numeric observations are processed in this tab and never uploaded. Only summary measures are displayed.

Enter independent groups

Paste numeric values for both groups.

Interpretation limits

  • The probability is P(group 1 > group 2) + 0.5 × P(tie) over all cross-group pairs; the rank-biserial effect is 2 × probability − 1.
  • This is a descriptive effect size related to the Mann–Whitney statistic, not a significance test or confidence interval.
  • Groups must be independent and numeric values must have a meaningful ordering. The direction depends on which group is entered first.
  • The tool supports up to 5,000 values per group and 5 million cross-group comparisons.
