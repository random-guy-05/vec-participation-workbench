Interpret each quantile with its coverage

  • Pinball loss is asymmetric around zero error according to the requested quantile; lower is better for the same outcome scale.
  • For a calibrated τ quantile, the observed outcome should fall at or below the forecast about τ of the time. Ties and finite samples affect the empirical fraction.
  • Quantile rows should use the same held-out cases. This tool does not create intervals, estimate uncertainty, or adjust for grouped observations.
  • Do not compare losses across different outcome units or transformations without a stated normalization.
