Cell-Label Mapping Auditor

Review a proposed mapping from stage-specific cell labels to shared analysis groups. Compare mapped composition by stage while keeping the original labels visible.

Mappings are supplied by you. This tool does not guess aliases, certify a harmonization, or infer cell lineage. All input stays in this browser tab.

Paste a stage-by-label table

Use one row per stage and raw label. Map related labels to the same canonical label only when you have evidence for that decision. Leave the canonical label blank or use UNMAPPED to keep a row unresolved.

Paste data or load the example to see mapped counts and unresolved labels.

Interpretation limits

  • A label absent from a stage may have been renamed, split, or left unannotated; a zero in this report is not evidence of biological absence.
  • Counts and percentages describe the input table. They do not adjust for sampling, dissection, batch, or annotation quality.
  • A shared label does not establish that cells are descendants of one another or that two labels are biologically equivalent.

The official Challenge data page notes that annotation vocabulary differs across stages and says a harmonized mapping is being developed. Check that page for updates before using your own mapping in a submission.
