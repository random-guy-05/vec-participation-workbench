Compare exact gene identifiers across two or more task or dataset panels. See intersections, panel-specific features, and Jaccard overlap, then export the shared identifiers for exploratory transfer planning.

Paste one identifier list per panel

Use one gene identifier per line, or separate identifiers with commas or spaces. Matching is exact and case-sensitive; this page does not map symbols, aliases, or orthologs.

Enter at least two identifier lists, then compare.

Use overlap as a planning aid

A shared panel can help scope a model that reuses features across tasks, while panel-specific genes may carry task-specific signal. The fraction in common does not measure biological equivalence, expression quality, or whether a transfer strategy will work.

The comparison uses only identifiers you paste and does not read or transmit files. Check the current official panel files before using any exported list in a submission.
