Interpretation limits

  • The exact test conditions on the observed row and column margins and uses a probability-ordering two-sided p-value.
  • Different software can define a two-sided Fisher p-value differently; report this convention when sharing results.
  • The raw odds ratio is not bias-corrected; zero cells can produce 0, infinity, or an undefined ratio.
  • The test does not adjust for confounding, clustering, multiple comparisons, or study design and does not establish causation.
