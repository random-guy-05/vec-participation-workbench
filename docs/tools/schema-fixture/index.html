Prediction Schema Fixture Generator

Create a deterministic local Python script that writes a synthetic AnnData prediction fixture with the selected board panel size and required spatial key.

The output has fake measurements and is for software smoke work only. It is not a biological prediction, baseline, valid score claim, or leaderboard submission. The generated script reads a local official panel file but does not download or transmit it.

Choose the output schema

The script requires numpy, pandas, scipy, and anndata in the environment where you run it.

Run it locally

  1. Download the exact one-gene-per-line panel file for the selected board from the official data page.
  2. Run the generated script in a Python environment that already has NumPy, pandas, SciPy, and AnnData installed. Pass the panel file path with --panel-file.
  3. Point your own pipeline at the generated H5AD file. The cell values and coordinates are random synthetic fixtures and must never be treated as Challenge data or a model result.

The generated file contains no cell-type labels and does not contain official answers. It uses sparse, non-negative synthetic expression; spatial tasks include obsm["spatial_3D"] with arbitrary local coordinates.
