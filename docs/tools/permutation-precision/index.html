Formulas and interpretation

p = (k + 1) / (B + 1)   ·   MCSE ≈ √(p(1 − p) / B)   ·   Bplan = ceil(q(1 − q) / targetMCSE²)

The add-one estimate avoids a reported zero when no shuffle exceeds the observed statistic. The minimum estimate it can report is 1/(B+1). The planning formula uses a binomial approximation for independent random shuffles and a presumed tail probability q.

The approximate interval is a Monte Carlo precision summary, not a confidence interval for a scientific effect or a substitute for the permutation test's assumptions. The tool does not evaluate exchangeability, choose a test statistic, or account for dependence among draws, finite-permutation corrections, data-sampling uncertainty, or multiple testing. Boundary counts (zero or all hits) make the normal approximation especially rough.

Inputs stay in this browser tab. Nothing is uploaded, stored, or fetched.
