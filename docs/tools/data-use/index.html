Important boundaries

  • The current data terms require appropriate acknowledgement and credit outside the Challenge.
  • Use of the unpublished Challenge dataset in a publication or public presentation requires prior written approval from the data-generating team.
  • External data used in a submission must be disclosed. Held-out stage/genotype restrictions still apply; this checklist cannot evaluate a particular dataset's biological proximity or license.

If unsure, check the live rules and data terms and seek organiser guidance before publishing.
