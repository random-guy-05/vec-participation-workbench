Do not confuse an average with pooled evaluation

  • The unweighted mean treats each fold score equally; the weighted mean gives larger folds more weight but is not necessarily the metric computed from pooled predictions.
  • Fold scores are dependent when training sets overlap. Their standard deviation describes observed spread; it is not a confidence interval or independent-replicate standard error.
  • All rows must represent the same metric definition, data split procedure, and scale.
  • This summary does not detect data leakage, choose a model, or quantify uncertainty for a future population.
