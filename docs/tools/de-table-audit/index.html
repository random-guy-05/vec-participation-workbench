Provide one row per reported gene. The auditor checks structure and value ranges; it does not repeat or validate the differential-expression analysis.

Paste results and read the column headers to begin.

What this audit checks

It reports repeated or blank identifiers, missing or nonnumeric effects, and missing, malformed, or out-of-range p-values for any selected p-value columns. It counts effect directions and values below the optional threshold without removing or reordering rows.

Duplicate IDs may represent transcripts, isoforms, or a merge error; decide from the analysis design rather than silently deduplicating. A valid p-value range does not establish correct modeling, independent replicates, a valid contrast, or appropriate multiple-testing correction.

Inputs stay in this browser tab. The tool does not upload, store, or fetch data. Limits: 5 MB of text and 200,000 data rows.
