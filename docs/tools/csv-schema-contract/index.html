CSV Schema Contract Validator

Check a table against a participant-written contract of required columns, basic types, and allowed values.

CSV and schema are processed in this tab. The issue report contains row, column, and issue code only—not cell contents.

Paste a CSV and a JSON contract

Contract keys: required (string array), types (string/number/integer/boolean), and allowed (string arrays). Column names match exactly.

CSV limit: 200,000 characters, 5,000 data rows, 100 columns.

RowColumnIssue

A contract checks structure, not scientific validity

  • Use the data dictionary or expected analysis inputs to write the contract; the tool does not infer column meaning or units.
  • CSV quoting, commas, escaped quotes, and line breaks inside quoted fields are parsed; encoding and separator variants beyond comma CSV are not inferred.
  • The report omits cell values to reduce accidental disclosure, but row numbers and column names can still be sensitive. Review before sharing.
  • A clean structural report does not validate provenance, data-use permission, missingness assumptions, or biological interpretation.
