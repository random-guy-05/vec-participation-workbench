Interpretation limits

  • Delimiter selection is a structural heuristic; quoted values can make naive character counts misleading.
  • A consistent width does not establish that headers or values have the intended meaning.
  • If delimiters tie or the file uses an unsupported encoding, inspect the original file with a trusted local editor.
  • Supports samples up to 5 MB and 20,000 rows. A pasted excerpt may not reveal problems elsewhere in a larger file.
