Interpret the estimates at the right level

The Wilson interval is a binomial interval for the within-sample proportion under a cell-level Bernoulli sampling approximation. It does not capture variation between biological samples, and within-sample dependence can make it too narrow. The unweighted mean gives each supplied sample equal weight; the pooled fraction gives larger samples more weight. The tool does not compute an interval or test for either cross-sample summary.

Use one row for each independent biological sample, not one row per cell or technical partition. This page does not infer replicate independence, rare-state identity, or experimental design. Inputs are processed locally and are not uploaded or stored.
