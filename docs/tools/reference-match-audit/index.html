Reference Match-Set Auditor

Check whether target and reference samples share exact user-selected metadata keys before building contrasts. The audit reports coverage; it does not decide that a reference is scientifically appropriate.

Paste one row per independent sample

Use one row per independent sample. Read the headers, choose sample and group columns, then select only scientifically justified matching fields.

Choose the columns that define a comparable set (for example, stage, genotype, or batch). Sample ID and group columns cannot be matching keys.

Paste the manifest and read column headers.

Interpret the match sets

Exact key agreement reveals which target samples have at least one reference sample under the selected columns. Multiple samples sharing a key are reported as a set; this tool never pairs them arbitrarily. Unmatched samples and incomplete keys need review before analysis.

Exact metadata agreement does not establish biological matching, exchangeability, independent replication, or correct control selection. Include only scientifically justified matching fields, and check current task rules.

The interface, instructions, and results are translated. Your pasted data stays in this browser tab and is not uploaded or stored. The downloaded CSV keeps its headers and status labels in English for interoperability.

Limits: 5 MB of text and 100,000 sample rows.
