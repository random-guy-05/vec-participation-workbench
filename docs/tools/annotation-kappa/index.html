Interpretation limits

  • Cohen’s kappa is for nominal categories and adjusts observed agreement for chance agreement from the observed label marginals.
  • Kappa can change with label prevalence and imbalance. Report the confusion counts and raw agreement alongside it.
  • Pairs must represent the same items and independent units. The tool does not infer matches, test significance, or establish annotation correctness.
  • This is different from adjusted Rand index and does not support ordinal weighting.
