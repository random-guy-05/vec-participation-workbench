Macro metrics expose class imbalance; they do not resolve it

  • Macro metrics give each class equal weight; weighted F1 weights by actual support. Report both when rare classes matter.
  • A class with no actual examples has undefined recall; a class never predicted has undefined precision. The page keeps these cases visible.
  • Rows must represent actual labels and columns predicted labels in the same held-out evaluation set.
  • No confidence intervals, threshold tuning, label mapping, or correction for clustered samples is performed.
