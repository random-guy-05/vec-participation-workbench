Run label, version, environment, and command make the card useful.



A run card supports a rerun; it does not certify one
  • Use a stable version identifier, exact command, environment lockfile, seed, and input/output checksum where permitted.
  • Never place credentials, access tokens, private filesystem paths, personal information, or restricted dataset identifiers in a public card.
  • Record what was actually executed. A card cannot prove the environment or outputs were unchanged.
  • Keep the appropriate data-use permission and source attribution with the project documentation.
