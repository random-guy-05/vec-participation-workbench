Notebook Execution Order Auditor

Find execution-counter and cell-ID inconsistencies that can reveal a notebook was run out of order.

Analysis stays in this tab. Findings include cell positions and issue types, never code or output text.

Paste notebook JSON

Paste a notebook JSON document to begin.

Interpretation limits

  • A decreasing execution counter is a clue, not proof that results are stale. Restarted kernels and edited notebooks can produce valid counter patterns.
  • The audit does not execute code, inspect source/output contents, or decide whether a notebook is scientifically reproducible.
  • Cell positions refer to the notebook's current order. Review flagged cells and rerun from a fresh kernel when appropriate.
  • Supports notebooks up to 5 MB and 1,000 cells. Input remains local and is never uploaded.
