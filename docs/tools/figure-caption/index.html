Make visuals accessible

Scientific Figure Description Builder

Draft concise alt text and a fuller description that tell readers what a figure shows, how to read it, and what it does not establish.

Keep short alt text concise; put detail and interpretation boundaries in the long description.

Describe, do not overstate

Alt text is not a substitute for the figure's caption or data source. Describe encodings and supported observations, preserve uncertainty, and do not claim a biological mechanism from a visualization alone.
