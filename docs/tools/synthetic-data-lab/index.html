Important limits

These are generated toy counts, labels, and optional coordinates. They are not copied from the Challenge, are not biologically validated, and do not follow an official task or submission schema. Never submit these files as Challenge predictions or use them to make biological claims. This page has no file upload and does not send data anywhere.
