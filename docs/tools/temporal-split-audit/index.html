Chronological Holdout Split Auditor

Check whether a sample-level split manifest keeps validation and test stages strictly later than training stages, and whether an optional subject or lineage group crosses partitions.

Paste one row per independent sample

Use a numeric stage-order column that you define (for example, an ordered stage index), a split label, and a stable sample ID. The auditor does not infer chronology from stage names.

Read the headers, select sample ID, numeric stage order, split label, and optional subject group.

Scope

A passing chronological check means only that the supplied numeric stage values are strictly ordered across the selected partitions. It does not prove that the order is biologically correct, prevent preprocessing or model-selection leakage, or replace a task-specific evaluation design. If a subject, lineage, or other correlated unit must stay together, select its group column and check the leakage count.

Inputs are processed in this browser tab and are not uploaded or stored. Limits: 5 MB of text and 200,000 sample rows.
