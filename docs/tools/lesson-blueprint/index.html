Teach one useful skill

Micro-Lesson Blueprint

Plan a short self-paced lesson that moves from one clear outcome to a worked example and a practice check, with answers and recovery hints.

Keep one lesson focused. Include an answer key so learners can continue without waiting for a mentor.

Teaching quality check

Test the lesson from the learner's starting point. Cite primary or official sources for challenge-specific facts, separate examples from official data, and state what the lesson does not cover.
