Compute planning

Runtime Forecast Planner

Estimate a larger run from real pilot timings on the same hardware and software stack. The planner fits a simple scaling curve and adds a conservative buffer.

1. Enter measured runs

One run per line: cells, genes, minutes. Use completed end-to-end runs with comparable settings. Do not mix different machines or workflows.

2. Enter the planned job

Enter at least two pilot runs, then forecast.

How to use the estimate

  • Measure the full path you plan to run, including data loading, preprocessing, model inference, and required output writing.
  • Use the same number of workers, device, precision, and caching behavior as the planned job.
  • The fit is an empirical extrapolation, not a benchmark guarantee. It cannot account for queue wait, failures, changing data, or contention from other users.
  • If the planned size is far beyond your largest pilot, run an intermediate pilot before committing scarce compute.

This tool forecasts elapsed run time only. It does not estimate RAM/VRAM or choose scheduler resources.
