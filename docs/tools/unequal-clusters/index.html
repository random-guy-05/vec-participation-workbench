Unequal Cluster Design Effect Explorer

Compare a balanced-cluster approximation with an unequal-size design effect using one observation count per independent sample and an assumed within-sample correlation.

Paste one row per independent sample, as sample_id,count, or paste one positive integer count per line. Use biological samples, not individual cells, as the clusters. Counts can represent cells, spots, or repeated measurements.

Review the example, choose an assumed ICC, and compare.

Approximation used

DEFF = 1 + (((1 + CV²) × mean cluster size) − 1) × ICC

The balanced comparison sets CV to zero while keeping the observed mean cluster size. Each effective observation count is total observations divided by its design effect. CV is calculated across the supplied sample counts using the population standard deviation.

This is a teaching approximation, not a fitted model, power analysis, confidence interval, or substitute for biological replication. ICC is an input scenario, not estimated from these counts. The effective observation count does not change how many independent samples you have. Informative cluster sizes, real correlation structures, covariates, unequal variances, and small numbers of clusters may need a more specific analysis.

Inputs remain in this browser tab. Nothing is uploaded, stored, or fetched.
