Compare gene-effect rankings across replicate-level result sets. See pairwise Spearman correlation, top-k Jaccard overlap, and sign agreement on genes shared by each pair.

Paste replicate-level effects

Use the same effect definition and direction across replicates. The analysis compares the entered results only.

Interpretation

Spearman correlation compares relative ranks among genes shared by a replicate pair. Top-k Jaccard summarizes set overlap, while sign agreement checks whether nonzero effects point in the same direction. These are descriptive summaries; high agreement does not establish biological truth or statistical significance.

Results can change with the feature universe, top-k, ties, and effect definition. This tool does not compute an official Challenge metric, align gene aliases, or replace sample-level inference. All data stay in this browser tab.
