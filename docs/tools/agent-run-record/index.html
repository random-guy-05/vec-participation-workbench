VEC Agent Run Lock & Evidence Record

Create a compact record of the configuration fixed at the start of one Agent Team run, then check that its required evidence is ready. This page does not upload or store your entries.

Before the run: configuration lock

Record the exact choices that are fixed when the run starts. Use a run ID and public or repository-relative artifact labels; do not paste credentials, private data, or unpublished results.

After the run: evidence packet

The current Rules require at least two distinct evidence kinds for an Agent Team submission, including the trajectory, and each item must correspond to this run. Record where each exact artifact is saved and whether it has been attached in the portal.

Review statements for this run
Fill the configuration and evidence fields, then build the record.

What this record checks

Rules §9 says a person may not inspect a locked Agent Team run's intermediate results and steer the next step. The required evidence kinds are trajectory, prompts, harness, and other material; at least two distinct kinds must be attached, one of them the trajectory. Choosing among completed runs is a separate decision.

Evidence is capped at 200 MB per file and 600 MB per team. The size fields are self-reported; this tool does not inspect files or verify portal uploads. It is a documentation aid, not an eligibility decision. Check the live rules before each submission.
