Review before sharing

  • The cleaner removes saved outputs and resets code-cell execution counts. It can also remove notebook-level widget state.
  • It does not inspect or redact code, Markdown, cell attachments, metadata other than widget state, or secrets embedded in source.
  • Review the cleaned copy manually for data, credentials, private paths, identifying names, and unpublished results before sharing.
  • The tool accepts notebooks up to 5 MB and 1,000 cells. It preserves the original input and does not claim the result is anonymous or safe to publish.
