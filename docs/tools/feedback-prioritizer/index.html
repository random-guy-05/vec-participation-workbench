Feedback Triage Planner

Compare one barrier at a time using a visible, editable impact/frequency/urgency/effort heuristic. The number helps structure discussion; it is not an official score or a substitute for affected users' input.

Formula: frequency × impact × urgency ÷ effort. Estimate each rating using the same anchors for every item; compare within your own backlog only.

Scores organize a conversation; write down reasons and uncertainty too.

Use the heuristic with care

Frequency and impact should be based on evidence where possible. A low-frequency barrier can still be serious. Revisit the choice with people affected by the issue; never use this number to decide a person's eligibility, access, or worth.
