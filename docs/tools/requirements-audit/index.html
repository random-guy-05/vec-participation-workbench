Python Dependency Pinning Review

Spot requirements that may resolve differently over time before sharing a project or asking for setup help.

Review runs locally. No package index or network lookup is used; this is a format triage, not a security audit.

Paste requirements.txt or a pip requirements file

Paste dependency lines to begin.

What this review means

  • Exact version pins improve repeatability but do not guarantee platform compatibility or identical results.
  • Unpinned direct URLs, editable installs, local paths, pip options, and nested requirements need human review; this tool does not follow includes.
  • No package is checked against an online index, and no vulnerability or license information is retrieved.
  • Names and specifiers are classified heuristically under common pip syntax. Review the original file before changing it.
