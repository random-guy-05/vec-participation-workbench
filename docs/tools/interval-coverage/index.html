Observed coverage is not a guarantee

  • Empirical coverage is the fraction of these outcomes inside their intervals; it is a marginal sample summary, not conditional coverage for every subgroup.
  • Mean width rewards narrower intervals, so interpret it together with coverage. The interval score penalizes misses more as they move farther beyond a bound.
  • Use genuinely held-out observations and report the nominal level and sampling unit. Repeated or clustered observations need design-aware uncertainty.
  • This tool does not calculate a confidence interval for coverage, recalibrate bounds, or validate how the prediction intervals were constructed.
