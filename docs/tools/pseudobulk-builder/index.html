Replicate-aware analysis · browser-local

Sample-Level Pseudobulk Matrix Builder

Convert long-form cell-by-gene values into sums for each independent sample. This makes the aggregation step explicit before downstream sample-level analysis.

Paste a long-form CSV

Use one row per sample, cell, and gene, for example sample_id,cell_id,gene_id,count. Values must be finite and nonnegative. The input is limited to 10 MB and 500,000 data rows.

The long-form export preserves observed sample–gene pairs and does not infer zeros for missing rows.
Paste data, read the headers, choose the four columns, and aggregate.

What the aggregation means

For each sample and gene, the tool sums the supplied cell-level values. It rejects duplicate sample–cell–gene rows so a repeated record cannot silently inflate a sum. Cell counts are distinct cell IDs within each sample; they do not establish that samples are independent biological replicates.

Use raw count values when a downstream count model expects counts. Fractional values are accepted but flagged; summing normalized or averaged values may not be appropriate. This page does not normalize, fit a differential-expression model, choose replicates, or perform inference.

Parsing and aggregation stay in this browser tab. Nothing is uploaded, stored, or fetched. Use public or synthetic data and follow the current Challenge data-use rules.
