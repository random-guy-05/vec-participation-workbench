A parity check is not a translation review

  • The audit detects missing, extra, blank, and placeholder-mismatched strings. It does not assess meaning, tone, grammar, cultural fit, or accessibility.
  • String placeholders such as {count}, {{name}}, and %s must match exactly; markup, ICU message syntax, and plural rules are not parsed.
  • Review flagged keys in context with a fluent human reviewer, and test the interface after merging changes.
  • The CSV contains key paths and issue types only. Keys can still reveal internal terminology, so review it before sharing.
