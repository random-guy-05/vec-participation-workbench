Compute Budget Estimator

Estimate the raw float32 storage for an expression prediction and, for spatial tasks, its coordinate array. Use the result to compare batch sizes and machine options before a run.

Change the task or cell count, then estimate.

What is included

  • T1 expression: n_cells × 32,285 genes × 4 bytes for float32.
  • T2/T3 expression: n_cells × 500 genes × 4 bytes, plus a three-coordinate float32 array.
  • The multiplier is a planning allowance for copies and temporary arrays, not a measured peak or guarantee.

The portal's upload limit and board-specific minimum/maximum cell counts apply separately. Check the current data page and submission validator. Sparse output, file compression, Python overhead, the model, and scorer memory are not estimated.
