Use and review
  • Run the generated script locally with Python 3; it uses only the standard library and reads files incrementally.
  • It skips symbolic links, sorts relative paths, and excludes the output manifest itself. Read errors stop the manifest from being written.
  • A checksum shows whether file bytes match a recorded value; it does not prove source authenticity, scientific validity, or eligibility.
  • Review the generated manifest before sharing: relative filenames can reveal project or participant details. Keep the original files unchanged.
