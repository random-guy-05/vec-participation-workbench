Methods

Experiment Plan Card

Write down the question, permitted inputs, and decision rule before an experiment. A short plan helps collaborators understand why a run happened and what its result can support.

Plan fields are kept in this page. No run data is collected.

Limitations

This is not a preregistration service and it does not enforce a study protocol. It cannot determine data eligibility. Check the current Rules before using external or held-out data. For a locked Agent Team run, keep the configuration fixed after the lock and do not inspect intermediate results to steer the run.
