H5AD Structure Profiler

Download a small Python script that reports AnnData shape, storage layout, metadata column names, and array dtypes without printing cell identifiers or expression values.

Use the local profiler

  1. Download the script and install h5py in the Python environment you plan to use.
  2. Run python vec_h5ad_structure_report.py path/to/file.h5ad to print a JSON report.
  3. Add --output report.json to save the report locally instead of printing it.

Download read-only H5AD profiler

The script opens the file read-only and inspects HDF5 metadata, dataset shapes, and dtypes. It does not read matrix values or identifiers into the report, and does not alter the input file.

What the report includes

  • Observation and variable counts when available.
  • The X or raw/X storage encoding, shape, dtype, compression, and sparse nonzero count when represented by standard sparse arrays.
  • Names and storage summaries for obs, var, obsm, varm, layers, pairwise arrays, and unstructured keys.

It is a structural inventory, not a schema validator. It does not confirm that columns have the right biological meaning, that data are eligible for a task, or that a model file is valid for submission.

A report still contains file and metadata field names. Review it before sharing. Keep Challenge data on approved storage and follow the current data-use rules.
