Notebook Revision Delta Auditor

Compare two notebook revisions by cell ID when possible, and summarize edits without printing code or outputs.

Both notebooks are processed in this tab. The report contains cell positions and change types only; source and outputs are never uploaded or displayed.

Paste two notebook JSON files

Paste both notebooks to begin.

Review limits

  • Stable cell IDs are used only when both revisions have unique IDs for every cell; otherwise matching falls back to cell position.
  • Position matching can report many changes after an insertion or deletion. Review a diff tool for the actual source change.
  • The audit does not compare notebook metadata, attachments, execution order, or output contents and does not establish reproducibility.
  • Supports up to 5 MB per notebook and 1,000 cells each. Keep a backup of both inputs.
