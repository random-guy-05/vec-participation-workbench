Sample-to-Cell Crosswalk Auditor

Check whether a sample manifest and a cell assignment table can be joined cleanly before aggregating expression or comparing groups.

1. Paste the sample manifest

Use one row per sample, with a stable sample identifier and any metadata columns you want to carry into the output.

2. Paste the cell assignment table

Use one row per cell and its assigned sample. The cell table may have other columns; select the two identifiers used in the join.

Some datasets reuse local cell IDs within each sample. Leave this unchecked unless the source defines cell IDs globally.

Read both headers, select the join columns, then audit.

Interpretation limits

An exact sample-ID match establishes only that the strings join. It does not prove that samples are independent, biological replicates, correctly staged, or scientifically comparable. Review unmatched IDs and source metadata with the data provider before analysis.

Each input is limited to 10 MB and 500,000 data rows. The page processes data locally in this browser tab and does not upload or store it. Use public or synthetic data.
