External Data Eligibility Checker

Screen an external dataset’s stage and condition against the Challenge’s published held-out boundaries before using it for training, fine-tuning, or transfer.

This is a conservative reading aid, not an organizer decision. It never uploads or stores your entries. Disclose every external source in your submission and check the current rules.

Describe the proposed source

Choose the task, enter the closest matching stage, and select “Screen this source.”

What the screen checks

  • Task 1’s published exclusion window after E9.5 through E13.5, including E10.5 and E12.5.
  • Task 2 embryo interpolation data strictly between released E7.25 and E8.0.
  • Task 2 heart interpolation data strictly between E8.25 and E8.75, plus extrapolation data closer to a held-out target than the nearest released stage.
  • Task 3 held-out Gata4 and β-catenin knockout conditions at E8.75, comparable alleles, and likely phenocopies when you identify them.

A result that passes the entered checks means only “no clear overlap found in these fields.” Stage harmonisation, mixed-stage releases, pretraining, genotype comparability, phenocopy, license, and source disclosure still need human review.
