Pilot Intraclass Correlation Estimator

Estimate one-way random-effects variance components from a continuous pilot outcome grouped by sample, and see how an unequal cluster-size design effect changes under that estimate.

Paste a pilot table

Use one observation per row, with a sample identifier and one numeric outcome. The sample identifier names the cluster; it is not assumed to prove biological independence.

Paste pilot observations and read the column headers.

Method and limits

The one-way method-of-moments estimate uses tau² = (MS_between − MS_within) / n₀, where n₀ = (N − Σnᵢ²/N)/(m−1). The estimated ICC is tau² / (tau² + sigma²_within). Negative estimates are retained as a diagnostic rather than truncated to zero.

This assumes a one-way random-intercept model with a common within-cluster variance and no covariate adjustment. It is not suitable for paired, nested, longitudinal, or otherwise structured designs without a model that represents that design. An ICC from pilot data is uncertain and is not a power calculation or an estimate of biological-replicate count.

Inputs remain in this browser tab. The page does not upload, store, or fetch data. Use public or synthetic pilot values. Limits: 5 MB of text and 200,000 observations.
