CSV Join Cardinality Auditor

Before joining two tables, see how many keys overlap, how many repeat, and how much a join could multiply rows or leave records unmatched.

This tool compares key counts only. It does not display or export raw key values, and nothing is uploaded or saved.

Paste two CSV samples

Use a header row and representative, non-sensitive rows. Each sample is limited to 20,000 records and 2 MB.

Audit the example or paste your own tables.

Interpretation limits

  • This estimates row counts for an exact equijoin on one chosen column. It does not create a joined dataset or assess whether the key is scientifically appropriate.
  • Blank keys never match one another; they are counted as unmatched records. Case remains significant; trimming is optional.
  • Duplicate keys on both sides can create many-to-many row multiplication. Review the key design before joining.
  • Results describe only the pasted rows. Run the same checks on complete source tables before an analysis.
