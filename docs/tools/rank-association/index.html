Pearson, Spearman, and Kendall Association Comparator

Compare linear Pearson association with tie-aware Spearman and Kendall rank associations on the same paired observations.

Only numeric pairs are processed in this tab. The report contains summaries, not row values.

Enter one x,y pair per line

Use comma or tab separation. A first header row is optional.

Paste at least three pairs.

Interpretation limits

  • Pearson summarizes linear association; Spearman uses average ranks and Kendall tau-b summarizes concordant versus discordant pairs with tie adjustment.
  • A gap between the two may reflect nonlinearity, influential values, or ties; inspect a scatterplot before drawing conclusions.
  • These coefficients do not imply causation. No p-values or confidence intervals are computed.
  • Pairs must be independent observations. The tool supports 3–10,000 pairs and does not upload data.
